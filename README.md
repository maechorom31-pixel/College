# 전문대 진학 탐색 🎓

전국 전문대학을 **지도**와 **조건 필터**로 탐색하고, **3개년 입결·전형별 등급·취업률·연계편입**까지
한 화면에서 비교하는 학생용 정적 사이트입니다.

> 2027학년도 전국 전문대학 입시 자료집(한국전문대학교육협의회) 기반
> **대학 127개 캠퍼스 · 학과 2,562개 · 수시 전형 8,561건 · 비교용 일반대 75개교**

## 주요 기능

### 탐색
- 🗺️ **시·도 지도** — 학과 수를 단일 색상 램프로 나타낸 단계구분도. 클릭하면 그 지역 학과로 이동
- 🔎 **조건 필터** — 권역(7개)·시도·계열(대/중/소)·인기학과(26종)·학제·취업률·등록금·경쟁률·평균등급
  · 정시 선발/연계편입/채용약정/신설학과/전형료 무료/간호·교직 보유 등 특성 필터
- 학과 ↔ 대학 뷰 전환, 카드/표 보기, 9가지 정렬, CSV 내보내기

### 인사이트 도구
- 🎯 **내 등급으로 찾기** — 내신 등급을 넣으면 최종등록자 평균·최저 등급과 대조해
  **안정 / 적정 / 도전 / 어려움**으로 분류. 전형 유형(일반·일반고·특성화고·대학자체기준)별 판정과,
  학과마다 가장 유리한 전형을 골라주는 **전형 무관** 모드 (판정 커버리지 39% → 82%)
- 📅 **전형 일정** — 모집시기별 원서접수·면접·실기·합격발표·등록·충원 일정.
  **면접·실기가 겹치는 날**을 찾아내 그날 시험 보는 대학만 추려 보여줌 (복수 지원해도 한 곳만 응시 가능)
- 🎓 **무시험 연계편입** — 전문대 → 4년제 편입 협약 매트릭스 + 학과별 편입 경로 422건
- 🆚 **전문대 vs 일반대** — 같은 등급대에서 중위권 일반대 75곳과 나란히 비교
- 📊 **데이터 인사이트** — 전형 유형별 등급 지형, 계열 비교, 경쟁률이 내려가는 학과, 가성비 학과
- ⚖️ **비교함** — 학과를 담아 표로 비교, 유리한 값 자동 강조, CSV·인쇄(PDF)

### 상세
- **학과 상세** — 3개년 경쟁률·등급 추이, 전형별 입결 표, 전형 유형별 등급 비교,
  정시 수능백분위, 학생부 반영방법, 학과소개·취업분야·취득자격증, 연계편입·채용약정 과정, 지원자격
- **대학 상세** — 3개년 취업률·충원율, 계열별 등록금, 전형 일정·전형료·복수지원 규정,
  동점자 처리 기준, 연계편입 협약, 개설 주요학과, 전체 학과 목록

## 기술
- 의존성 없는 **순수 HTML/CSS/JS** 정적 사이트 (외부 지도 API·차트 라이브러리 없음)
- 지도·차트 모두 자체 SVG/CSS 구현 → 무료 호스팅(GitHub Pages 등) 가능
- 초기 로드는 3개 파일(약 1.6MB)만 받고, 상세·도구용 데이터는 **필요할 때 지연 로드**

### 데이터 색상 규칙
- 범주형(계열·전형 트랙): 검증된 8색 팔레트를 **고정 순서**로 사용, 순환하지 않음
- 크기(학과 수): 파랑 단일 색상 램프 (밝음 → 진함)
- 상태(안정/적정/도전): 상태 전용 색 + **항상 아이콘·라벨 동반** (색만으로 의미를 전달하지 않음)
- 모든 차트에 직접 라벨과 표 대체 뷰를 제공

## 구조
```
index.html               진입점
css/style.css            스타일
js/store.js              데이터 저장소·지연 로더·공통 유틸
js/charts.js             SVG/CSS 차트 (막대·가로막대·추이선·등급밴드·누적)
js/koreaGeo.js           시·도 경계 좌표
js/koreaMap.js           시·도 단계구분도
js/app.js                라우터 · 홈 · 탐색 · 비교함
js/detail.js             학과 상세 모달 · 대학 상세 페이지
js/tools.js              등급매칭 · 일정 · 연계편입 · 일반대비교 · 인사이트
data/*.json              사이트용 정제 데이터 (아래 참조)
scripts/build_data.py    엑셀 → JSON 변환 파이프라인
기획서.md                분석·설계 문서
```

### 데이터 파일
| 파일 | 내용 | 로드 |
|---|---|---|
| `meta.json` | 필터 옵션·집계·인사이트 | 즉시 |
| `colleges.json` | 대학 127개: 취업률·충원율·등록금·일정·전형료·복수지원·주요학과·편입 | 즉시 |
| `departments.json` | 학과 2,562개 핵심 + 대표 입결 + 트랙별 등급 | 즉시 |
| `admissions.json` | 전형별 입결 8,561행 (3개년 경쟁률·등급, 학생부 반영방법) | 지연 |
| `jeongsi.json` | 정시·트랙별 입결 (수능백분위 포함) | 지연 |
| `dept_info.json` | 학과소개·취업분야·취득자격증·혜택 | 지연 |
| `extras.json` | 지원자격·연계편입 상세·주문식 교육과정·수능최저 | 지연 |
| `univ.json` | 전문대 vs 일반대 비교 | 지연 |

## 로컬 실행
```bash
python3 -m http.server 8000   # file:// 은 fetch 제한이 있어 서버로 열기
# http://localhost:8000 접속
```

## 데이터 재생성
원본 엑셀을 `data/source.xlsx`로 두고:
```bash
pip install openpyxl
python3 scripts/build_data.py
```

> 입결은 2026학년도 실적이라 해마다 변동이 있습니다. 최종 지원 전 반드시 각 대학 모집요강을 확인하세요.
