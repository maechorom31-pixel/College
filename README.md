# 전문대 진학 탐색 🎓

전국 전문대학을 **권역 지도**와 **조건 필터**로 탐색하고, **입결·취업률**을 그래프로 비교하는 학생용 정적 사이트입니다.
(2027학년도 전국 전문대학 입시 자료집 기반 · 대학 127개 / 학과 2,302개)

## 주요 기능
- 🗺️ **권역 지도 탐색** — 4개 권역(수도권/중부권/영남권/호남권)을 클릭해 지역별 대학·학과로 이동
- 🔎 **조건 필터 검색** — 권역·시도·계열(대/중/소분류)·취업률·등록금·경쟁률·키워드
- 📊 **입결/취업률 그래프** — 취업률·충원율 3개년 추이, 계열별 등록금, 입결(2025 vs 2026) 비교
- 학과 ↔ 대학 뷰 전환, 카드/표 보기, 다양한 정렬

## 기술
- 의존성 없는 **순수 HTML/CSS/JS** 정적 사이트 (외부 지도 API·차트 라이브러리 불필요)
- 지도·차트 모두 자체 SVG로 구현 → 어디서나 빠르게 동작, 무료 호스팅(GitHub Pages 등) 가능

## 구조
```
index.html          진입점
css/style.css       스타일
js/koreaMap.js      권역 SVG 지도 생성
js/charts.js        미니 SVG 차트(막대/추이선)
js/app.js           라우팅·필터·결과·상세 모달
data/*.json         사이트용 정제 데이터 (colleges/departments/meta)
scripts/build_data.py  엑셀 → JSON 변환 파이프라인
기획서.md           분석·설계 문서
```

## 로컬 실행
```bash
python3 -m http.server 8000   # file:// 는 fetch 제한이 있어 서버로 열기
# http://localhost:8000 접속
```

## 데이터 재생성
원본 엑셀을 `data/source.xlsx`로 두고:
```bash
pip install openpyxl
python3 scripts/build_data.py
```

> 학습·참고용 탐색 도구입니다. 입결/취업률은 미발표 시 "정보없음"으로 표시되며,
> 최종 지원 전 반드시 각 대학 모집요강을 확인하세요.
